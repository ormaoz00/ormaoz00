# Claude, Skills ו-MCP — מדריך פשוט

---

## המושג הבסיסי — Claude לבד

תדמיין שיש לך עובד חכם מאוד.  
הוא יודע לחשוב, לנתח, לכתוב ולהסביר.  
אבל הוא יושב **בחדר סגור**.

זה Claude.

> Claude לבד יודע לחשוב — אבל לא יודע לפעול בעולם האמיתי.

---

## שכבה ראשונה — Skills

**Skill זה כמו ללמד את העובד תפקיד.**

במקום עובד כללי, אתה הופך אותו למשהו ספציפי:

- איש מכירות
- אנליסט לידים
- כותב קופי
- מנהל משימות

כל Skill אומר לו:
- איך לחשוב
- איך לנתח
- איך להגיב

> **חשוב:** Skill לא נותן לו כוח לבצע פעולות — רק משפר את החשיבה שלו.

---

## שכבה שנייה — MCP

**MCP זה מה שנותן לעובד ידיים.**

עכשיו הוא לא רק חושב — הוא גם יכול לפעול:

- לקרוא נתונים ממערכת
- להכניס לידים ל-CRM
- לעדכן Google Sheets
- לשלוח הודעות

| | תפקיד |
|---|---|
| **Skill** | המוח — איך לחשוב |
| **MCP** | הידיים — איך לפעול |

---

## ההבדל בין MCP ל-SSO

| | תיאור |
|---|---|
| **SSO** | רק כניסה — כמו **מפתח לבניין** |
| **MCP** | מה אתה יכול לעשות בתוך הבניין — לאיזה חדרים אתה נכנס ומה מותר לך לבצע שם |

> SSO מזהה אותך. MCP מגדיר מה אתה מורשה לעשות.

---

## סיכום

| רכיב | מה זה |
|---|---|
| **Claude** | עובד חכם שיודע לחשוב |
| **Skill** | תפקיד שאתה נותן לו — איך לעבוד ואיך לחשוב |
| **MCP** | היכולת לפעול בעולם — לעשות פעולות אמיתיות |

---

## איך הכל מתחבר — דוגמה אמיתית

**תרחיש:** נכנס ליד חדש

1. Claude מבין את הליד
2. Skill מנתח אותו ומדרג איכות
3. MCP מכניס אותו ל-CRM
4. Claude מציע הודעת המשך

> וזה כבר לא "עוזר" — זה **עובד בצוות שלך**.

---

## התובנה החשובה

רוב האנשים משתמשים ב-Claude רק לחשיבה.  
מי שמבין Skills ו-MCP — הופך אותו למערכת עבודה.
